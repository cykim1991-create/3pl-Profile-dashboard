# 협력사 유상운송보험 가입 확인 안내 페이지

12/3 유상운송보험 가입 확인 유예기간 종료에 맞춰, 협력사 사장님이 챙겨야 할 내용을 정리한 읽기 전용 Apps Script 웹앱.

## 커뮤니케이션 방향

- 협력사 라이더도 의무화 대상이라 유상운송보험에 가입해야 한다.
- 협력사 라이더의 관리 주체는 협력사이므로, 소속 라이더의 보험 가입 여부 확인은 사장님이 해야 한다.
- 미가입이 가능하다고 읽히는 표현, 플랫폼이 직접 관리한다는 뉘앙스, "12/3부터 의무화" 표현은 쓰지 않는다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | `doGet` — `Index.html` 을 그대로 내보낸다 |
| `Index.html` | 안내 페이지 (입력·저장 없음) |

## 배포

> ⚠️ 사장님은 사내 계정이 없어서 액세스 권한을 **모든 사용자**로 열어야 한다. 외부 공개 전 Slack `#support-정보보안` 사전 검토, 문구는 정책협력팀 리스크 검토를 받는다.

1. [script.google.com](https://script.google.com) 에서 새 프로젝트 생성
2. `Code.gs` 붙여넣기, **파일 > HTML** 로 `Index` 추가 후 `Index.html` 붙여넣기
3. **배포 > 새 배포 > 유형: 웹 앱** — 실행 계정 **나**, 액세스 권한 **모든 사용자**
4. 발급된 `/exec` URL을 시크릿 창(로그인 없음)에서 열어 확인한 뒤 안내문에 넣는다

문구를 고친 뒤에는 **배포 관리 > 수정 > 새 버전**으로 다시 배포해야 반영된다 (URL 유지).
