# 실시간 운영 현황 개편 안내 · 사용성 설문 웹앱

배민커넥트비즈 '배달현황' → '실시간 운영 현황' 개편 내용을 협력사에 가볍게 소개하고, 바뀐 기능별 사용성 설문을 받는 Apps Script 웹앱.

## 파일

| 파일 | 역할 |
| --- | --- |
| `Config.gs` | 문항 정의 (기본 정보 · 변화 항목 · 척도 · 의견). 화면과 서버 검증이 함께 쓴다 |
| `Code.gs` | `doGet` · 제출 검증·저장 · `setup`(응답 탭·헤더 생성) · `summary`(항목별 평균) |
| `Index.html` | 소개(전후 비교 · 변화 목록) + 설문 폼 + 완료 화면 |

## 화면 구성

1. **이런 변화가 있어요**: 이전/이후 토글로 화면을 비교하고, 변화 항목 8개를 카드로 보여 준다 (신규/개선 태그, 이전 방식 한 줄)
2. **설문**
   - 기본 정보: 운영 지역(복수 선택) · 계약 유형(직계약/중개사) · 자체·외주 개발 도구 사용 여부
   - 바뀐 기능 평가: 8개 항목을 5점 척도로 평가. 안 써 본 항목은 `안 써 봤어요`, 협력사 변경은 `해당 없음`
   - 전체 의견: 전체 만족도(5점, 필수) + 자유 의견(선택, 1,000자)

화면의 예시 숫자·라벨(라이더A 등)은 모두 가상 값이다.

## 수집 범위

- 저장: 제출일시, 위 문항 응답, 제출ID(브라우저에서 만든 무작위 값, 중복 제출 방지용)
- **저장하지 않음**: 이름·연락처·협력사명·협력사 ID·접속 계정·IP
- 응답 시트를 검토할 때 자유 의견 칸에 개인정보가 들어 있으면 지운다.

## 남용 방지

- 서버가 선택지 목록에 있는 값만 받는다 (임의 값이면 저장 안 함)
- 제출ID 6시간 중복 차단, 분당 전체 60건 상한, 숨긴 입력칸(봇 차단용)
- 의견은 1,000자로 자르고, `=`·`+`·`-`·`@` 로 시작하면 앞에 `'` 를 붙여 시트 수식 실행을 막는다

## 배포

> ⚠️ 협력사는 사내 계정이 없어서 액세스 권한을 **모든 사용자**로 열어야 한다. 사내 Apps Script 웹앱 외부 공개는 보안 정책상 막혀 있을 수 있으니 **배포 전에 Slack `#support-정보보안` 에 사전 검토를 요청**할 것.

1. [script.google.com](https://script.google.com) 에서 새 프로젝트 생성
2. `Code.gs`, `Config.gs` 를 각각 스크립트 파일로 붙여넣고, `Index.html` 은 **파일 > HTML** 로 추가 (파일명 `Index`)
3. **프로젝트 설정 > 시간대**를 `(GMT+09:00) 서울`로 지정
4. 편집기에서 `setup` 실행(▶) → 권한 승인 → 응답 시트에 `응답` 탭과 헤더가 생겼는지 확인
   - 응답 시트: [배민커넥트비즈 최적화 설문](https://docs.google.com/spreadsheets/d/1xWR4U30E8F1ydc7Dq8SantheTlDrd_Na1YRQczpqp0g/edit) (`Code.gs` 의 `SHEET_ID`)
   - 배포자 계정에 이 시트의 편집 권한이 있어야 한다. 시트 공유는 사내 담당자로만 유지한다
5. **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (정보보안 검토 통과 후)
6. 발급된 `/exec` URL로 접속해 테스트 응답 1건 제출 → 시트에 들어갔는지 확인 → 테스트 행 삭제 후 협력사에 안내

문항을 고친 뒤에는 **배포 관리 > 수정 > 새 버전**으로 다시 배포해야 반영된다 (URL은 그대로 유지).

## 결과 보기

- 편집기에서 `summary` 실행: 항목별 평균 점수 · 평가 수 · 미사용 수를 실행 기록에 출력
- 세부 분석은 응답 시트에서 계약 유형 · 자체 개발 도구 사용 여부 · 지역별로 필터링한다

## 주의

- 응답이 쌓인 뒤 `Config.gs` 의 문항 순서나 key 를 바꾸면 시트 컬럼과 어긋난다. 바꿔야 하면 기존 `응답` 탭 이름을 바꿔 보관하고 `setup` 을 다시 실행해 새 탭으로 시작한다.
- 설문 기간이 끝나면 **배포 관리 > 보관**으로 웹앱을 내린다.
